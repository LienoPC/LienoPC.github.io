N-Body Cuda Simulation

Project that implements a GPU-accelerated simulation of an N-body system utilizing the all-pairs approach. The application computes gravitational interactions using NVIDIA CUDA, supplemented by real-time visualization and performance benchmarking.

  • Parametric tiling with Shared Memory that decouples tile width from thread block size.
  • Multi-threaded OpenMP reference implementation providing lockstep verification and adaptive tolerance analysis for floating-point calculations.
  • Runtime GPU profiling and optimization based on parallel programming techniques.
